# Personal Site Launch · 个人网站从零到上线

帮助非技术用户通过 Codex、Kimi Code 等 Agent，构建个人展示网站，并交付本地文件夹自动更新、结果通知和经过验证的恢复方法。

## 使用

将完整技能目录交给目标 Agent，按它支持的技能加载方式安装；具体适配和限制见 [环境说明](references/environment.md)。也可以让具有必要本地执行能力的 Agent 读取 [SKILL.md](SKILL.md)。

建议起始请求：

> 请使用 personal-site-launch 帮我建立个人展示网站。我没有技术背景，请先聊清楚需求，用图片让我确认设计，然后完成上线、文件夹自动更新和实际验收。

Codex 中可显式调用 `$personal-site-launch`。Kimi Code 的加载方式见环境说明；不同品牌下的云端聊天和本地代码 Agent 不能视为同一执行环境。

## 包含什么

- 通用建站流程：需求沟通、设计确认、实际开发、上线与交接。
- 普通文本素材模板，以及只读的文本转换和校验工具。
- 必须实施的文件夹自动更新、断网恢复、有限重试、成功/失败/停止通知要求。
- 页面、自动更新、用户自主操作和真实版本恢复的验收清单。
- 可持续维护的项目记录和操作说明模板。

核心入口不绑定特定 Agent、操作系统、网站框架或托管平台。个人介绍、作品、文章、视频及项目展示属于范围；登录、支付等复杂业务需另行界定。

## 完成标准

网站真实上线，用户亲自完成一次内容更新并看到页面变化、收到结果通知，同时持有简明操作说明和经过演练的恢复方法。Agent 自己运行测试不能代替用户自主更新验收。

## 验证与限制

技能格式检查和普通文本转换器的 21 项行为测试已通过，详见 [验证记录](docs/VALIDATION.md)。

```sh
python3 scripts/test_parse_content.py
```

本仓库是 skill 与辅助工具，并不是已为所有电脑安装好的通用发布器。执行此 skill 的 Agent 需要针对实际项目构建、配置和验证后台更新程序。Kimi Code、Windows/Linux 及其他用户新网站的全流程尚未实机验证，不能将格式兼容视为端到端验证通过。
